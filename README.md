# 珠光小店物语 · 手串工坊

彩铅、水彩与纸张质感的手机竖屏游戏原型。父母在阿禾幼年车祸离世，她与奶奶相依为命，面对叔婶侵占遗产和持续欺压，从手作小店开始挣得独立生活的底气。

## 试玩

https://mengpingchen954-ops.github.io/pencil-bead-atelier/

支持触屏与鼠标；需要支持 WebGL 的现代浏览器。原型包含 6 份定制委托、3 章连续剧情（7 段主线、3 段装修支线）、6 种珠材、3 类可升级家具、作品收藏、线索与回忆手账及本地自动存档。

## 玩法

1. 在珠材花园交换相邻珠子，同色横竖直线三颗起消，2×2 四颗同色方块也能消除。16 步内完成目标获得六色珠材包。小木槌、花开十字和重新排珠有每关限量次数，灵感提示免费。
2. 在工坊点珠材依次串入 12 个位置。点选已有珠子后可以替换、取下；拖动珠子可以交换位置。挑选合适吊坠，满足订单要求再包装交付。
3. 交付消耗真实库存，获得金币、口碑与剧情进展。金币能升级奶奶的椅子、展示柜和工作桌，完成的实际配珠会保存在图鉴中。
4. 首页显示当前剧情压力与行动目标。交付推进主线，首次升级家具解锁生活支线；读完对应剧情后收好相关记录。手账支持未读提示、物件阅读和故事重温，重温不重复发奖励。

## 剧情和后续视频

本篇从第一笔自主收入，推进到保护原创、拒绝苛刻合作与准备核查遗产资料。叔婶的压力持续出现，阿禾的应对逐步成长。遗产尚未追回，不把六份订单写成所有问题已经解决。

完整章节建议、逐段视频清单与接入方法：[剧情与视频接入](docs/剧情与视频接入.md)。视频放在 `public/videos/`，填写 `public/story-media.json` 对应的稳定剧情 ID 即可。当前视频条目为空，默认使用完整对白。支持点击播放、字幕、切换文字、播放失败回退、后台暂停和手账重温。

体力每 3 分钟恢复一点，上限 10；采珠一次消耗一点。串珠和装修不消耗体力。进度保存在当前浏览器，清除站点数据会清除进度。全部订单完成后，可继续采珠和自由配珠。

电脑上 F 切换全屏，Esc 关闭弹窗或返回。棋盘获得焦点后，方向键移动光标，空格选珠并交换相邻格。

## 本地运行

使用 Node.js 24：

```sh
npm ci
npm run dev
```

开发地址 http://127.0.0.1:5217 。`npm run build` 生成 `dist/`；使用相对资源路径以支持 GitHub Pages 仓库子路径。

```sh
npm test
npx playwright install chromium
npm run test:browser
npm run test:feel
npm run test:story
npm run test:square
```

`GAME_URL` 可指定浏览器测试目标。测试从实际界面完成采珠、手工配珠、拖动换位、全部委托、装修、剧情、存档恢复、失败重试与手机/桌面布局，并检查控制台和资源请求。基础试玩截图保存在不提交的 `artifacts/`；剧情测试截图放在系统临时目录 `bead-story-qa`。视频测试用内存生成的短片验证真实播放结束、字幕、跳过、重温、损坏回退和播放被拒绝，不发布测试影片。

## 视觉与技术

- Three.js 原生 WebGL：三消棋盘、射线拾取、珠子拖动、三维手串、金属隔珠、吊坠和消除粒子。
- 三消手感：跟手拖动与方向锁定、平滑交换及无效交换回位、消除蓄力缩放、按真实列位置下落、落地压缩回弹、珠材飞入计数栏、递进连消音阶与轻微局部震动。动画期间可预输入一次操作，减少动态效果模式使用同一套结算规则。
- Canvas 绘制六种不同轮廓的彩铅珠材、珠子材质与工作台纸纹；SVG 绘制工具、导航、家具与花卉。
- 插画为用户提供的彩铅参考稿裁切，裁切来源见 `public/art/sources.json`；其余界面为可交互的 HTML/CSS，没有把整张界面图当作按钮。
- 本次环境未提供可调用的 imagegen，采用提供的插画和程序化美术完成视觉。未调用付费生成接口。
- 模型规则与 Three.js 场景独立，存档进行字段验证；交付奖励与家具扣款均为原子更新。
- `window.render_game_to_text()` 提供只读状态，`window.advanceTime(ms)` 用于视觉检查。

这是浏览器原型，尚未封装原生安装包；不包含账号、云存档、真实交易或完整长线运营内容。
