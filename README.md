# 珠光小店物语 · Cocos Creator 版

[直接试玩](https://mengpingchen954-ops.github.io/pencil-bead-atelier/)

当前公开版使用 **Cocos Creator 3.8.2** 原生节点、Graphics、Sprite、Label、音频与触控事件实现。完整工程在 [cocos/](cocos/)，用 Dashboard 打开后运行 assets/scenes/Atelier.scene。

UI 布局已重新整理：首页以横幅插画、当前委托和主操作分区，委托信息与备料状态合并，故事 / 手账 / 比赛集中在下方；菜单页减少装饰边框，顶部资源和底部导航统一间距。委托每页三份并自动定位当前顾客，手账每页四段，已解锁与待解锁内容区分显示；当前心愿可展开完整内容。旧存档和原有玩法继续保留。

已迁移三消采珠、连消与工具、十二槽手串拖动制作、六份委托、十一处清理、修屋与家具升级、三章主线及生活支线、作品图鉴、回忆手账与自动存档。保留原插画、剧情、库存及经营规则。支持鼠标、触屏、键盘和浏览器屏幕阅读器；游戏页面由 Cocos 渲染。

本轮优先优化首条作品：赠送足够首单材料，一句需求后直接进入制作；点击珠材先弹到圆心，再弹入随机空槽，全程保持原朝向，之后可拖动调整；明确保留替换 / 移除与撤销。首单完成先放大欣赏，再包装、听顾客反馈并接第二单。前三关以当前订单缺料为主目标，已采珠材随消除保存，失败 / 退出可保留，最终不重复领取。进度导出包含本机五步首次时间，真人两分钟完成与满意度仍待试玩检验。

最新优化加入前15关独立目标与障碍布局、四连丝线珠 / 五连花束珠及连锁、纸袋与线结、委托缺料提示、实时目标反馈与定向补给。领奖后回顾客手作台；修屋和家具升级带有新旧房间渐变及奶奶回应。彩铅插画、持续顾客委托与旧进度继续保留。第16关起循环这15套关卡配置。

来订单时新增参考图形式的「新订单」页面：奶奶提示、花边珠宝柜、发光订单卡和阿禾构思插画，实时显示顾客 / 作品名、主辅珠材需求与库存、吊坠、酬谢。首页订单卡、「按单制作」和委托列表均可进入；跳过引导只隐藏奶奶与指引手势，点卡片或「开始制作」进入原委托工坊。缺料可去采珠，预览不扣材料、金币、体力，草稿与吊坠保持原样。Creator Page「新订单」可编辑。

收藏作品新增全屏放大详情：花卉蕾丝与金色边框、真实手串与材料数量、顾客心意和系列信息；保留小满的祝福 / 包装 / 旅行挂件。「查看订单故事」只读重温对应剧情，「再做一条」确认后沿用配色制作当前顾客委托，可撤销，原收藏不变。Creator 第十八个 Page「收藏详情」可编辑。

订单交付已按参考图改为完整结算页：递交礼盒插画、实际手串、金币与信誉、收藏解锁和「继续营业」。回执随奖励保存，刷新不会重复发奖；继续后接原有顾客剧情，保留小满的祝福回应和回头客委托。Creator 的 Page 下拉框可切换到「订单交付」编辑布局。

剧情对话按新参考图采用全屏小店人物场景、底部姓名与对白框、右上「记录 / 跳过」。记录可分页查看已读内容并回到原句；主线、家具支线、小满聊天与回应使用同一套界面。Creator 的 Page「剧情对话」可以编辑布局。人物使用提供的祖孙插画，其他角色暂以真实姓名和对白呈现。

「手账 → 人物故事 · 回忆」新增参考图形式的人物回忆页：奶奶珠盒大图、关系阶段、分页已知经历、相关实际作品与人物切换。奶奶、阿禾及三位顾客按已有剧情和订单进度解锁，未知经历不提前显示；底部制作按钮返回当前顾客委托。Creator 现有17个可编辑页面，包括「人物回忆」「成品包装」「故事解锁」「暂停游戏」「新订单」。

订单收藏「图鉴」采用金色花边相册、双列真实作品与未收集卡、系列完成进度、原生搜索与系列筛选。按现有三章和回头客近六单浏览，显示实际配珠、吊坠、小满祝福和旅行纪念挂件；搜索不会改变收藏进度。底部「制作新手串」继续当前顾客委托，四个插画入口连接店铺、图鉴、任务和手账。Creator Page「图鉴」可编辑。

首页「故事解锁」或手账「故事路线 · 解锁」进入珠链故事地图：五个插画节点对应现有七段主线，实际订单决定解锁，主线已读数量决定阅读进度。点击节点可查看章节、阅读或重温；锁定节点提示具体委托。底部继续故事会接下一段可读主线，没有新剧情时引导制作当前顾客订单。背包、图鉴和回忆手账均连接原有功能。此图是已有故事的浏览方式，不新增可经营地点或剧情奖励。

订单制作采用需求卡、环形珠槽、简洁珠材栏和撤销 / 移除 / 预览 / 完成制作。已移除方形托盘、圆形底板与卷轴装饰，让珠子直接呈现在纸面上。需求卡和珠材显示实时委托与库存；预览显示实际作品，满足订单后进入包装。继续支持随机落珠、拖动换位与撤销；比赛保持独立草稿与珠材。

成品确认采用参考图的打开礼盒、人物陪伴、花卉祝福卡和双按钮布局。礼盒中显示实际十二颗珠子与吊坠，可返回继续修改；海风订单可选择已解锁的祝福、信纸和丝带。完成包装保留所选方案，使用默认包装则恢复默认三项后交付；仅交付时扣库存和结算，进入已有结算页。普通及回头客订单使用默认祝福。

美术按用户提供的「铅笔2」参考细化：人物柜台纵深插画、俯视透视托盘、独立珠材与接触阴影、斜俯视装修、复古花边和纸张纹理。43 张生产纹理及裁剪来源记录在 Cocos 工程内，`cocos/tools/prepare-pencil-art.py` 重建原24张素材，再依次运行 `prepare-delivery-art.py`、`prepare-dialogue-art.py`、`prepare-memory-art.py`、`prepare-packing-art.py`、`prepare-story-route-art.py`、`prepare-commission-art.py`、`prepare-pause-art.py` 并传入对应参考图提取新增插画。标题、结算、对白、经历、选项和按钮均为实时 Cocos 节点。

暂停面板按花卉蕾丝参考图制作，采珠和订单制作共用：音乐 / 音效 / 减少动效开关，切歌与音量，继续游戏、当前关卡或作品重开、返回店铺。继续保留实际操作状态，重开与退出说明具体影响；采珠重开仍消耗 1 体力，作品重开可撤销，完整存档保留。Creator 的 Page「暂停游戏」可编辑。

旧网页「设置 → 导出」的 JSON 可在本版「设置 → 导出 / 导入存档」中继续使用。同一站点的合法旧存档会自动读取；不同浏览器与原生平台之间需手动导入。

## 工程与构建

- [cocos/README.md](cocos/README.md)：运行方式、文件结构、存档迁移与平台说明。
- cocos/build-game.ps1：调用已安装 Creator，使用正式构建配置生成 cocos/build/web-mobile。
- `scripts/package-cocos.ps1 -Project <工程绝对路径>`：同步已构建工程的预期源码与浏览器产物，排除编辑器私人配置，并重建校验清单。
- cocos-web/：已经 Creator 构建并验证的 Web Mobile 产物，GitHub Actions 发布此目录。
- cocos-web/build-manifest.json：工程与产物 SHA-256 清单。CI 检查两者一致，避免修改源文件后仍发布旧构建。Creator 编译在本地安装环境执行，Actions 验证产物后部署。

使用 Node.js 24 执行：

```sh
node --test cocos/tests/*.mjs
node scripts/verify-cocos-build.mjs
```

浏览器验收：设置 `GAME_URL` 后运行 `node scripts/test-cocos-polish.mjs`，逐关操作正式 Cocos 构建并检查订单交付、领奖、失败重试、装修保存与手机 / 桌面布局。`node scripts/test-cocos-delivery.mjs` 专门检查六份订单、回头客、实际作品与奖励、刷新回执、祝福回应和三种宽度。

`node scripts/test-cocos-dialogue.mjs` 检查全部十段剧情、逐句内容、记录分页与返回、触屏继续及跳过、小满聊天和交付回应、存档与三种宽度。

`node scripts/test-cocos-memories.mjs` 检查五位人物、解锁与已知经历、重温、真实收藏作品、触屏切换、回当前委托和三种宽度。

`node scripts/test-cocos-packing.mjs` 检查真实成品、返回修改、触屏包装、海风选择与默认重置、单次结算、刷新和三种宽度。

`node scripts/test-cocos-story-route.mjs` 检查五个真实解锁节点、七段主线与重温、原生触屏、背包 / 设置 / 图鉴 / 回忆入口、保存、订单与资源不变，以及三种宽度。

包含 83 项 Cocos 规则、控制器与场景测试，其中一项直接载入 Creator 正式编译模块，覆盖全部委托、装修、剧情和存档恢复。`node scripts/test-cocos-ui.mjs` 验证新布局的原生点击、委托与手账分页、当前顾客定位、缺料路线、进度保存和 360 / 390 / 540 / 1440 四种宽度。

Web Mobile 构建可通过静态 HTTP 服务试玩。Android、iOS 和小游戏平台需要在 Creator 中配置相应 SDK 后另行构建，本仓库不包含这些平台安装包。

## 网页原型

原 Three.js 网页源码保留在 src/、public/ 和 tests/，原说明归档在 [docs/网页原型说明.md](docs/网页原型说明.md)。根目录 Vite 开发命令用于该历史原型；Cocos 版不依赖 Three.js 或 WebView。

`node scripts/test-cocos-workshop.mjs` 检查原生触屏落珠与换位、指定空槽、替换、移除与撤销、真实作品预览、订单校验、包装衔接、缺料、海风聊天、比赛隔离与奖励、刷新和三种宽度。

`node scripts/test-cocos-pause.mjs` 检查实际暂停界面、三个开关、真实背景音乐播放与音量、底层输入阻挡、棋盘继续、重开与退出的体力 / 库存、零体力、草稿撤销和三种宽度。
