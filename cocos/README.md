# 珠光小店物语 · Cocos Creator 原生版

当前版本使用自由DIY与售珠橱窗：所有关卡所得实时入库，珠子种类和数量自由搭配，保存成品时扣料，定价上架后售出才获得金币；售出件数解锁剧情和赛事。规则由 `commerce.ts` 实现，旧存档与收藏保留。新流程浏览器验收使用根目录 `scripts/test-cocos-commerce.mjs`。DIY桌台按四张011参考图采用花卉蕾丝圆盘与四类材料网格；36种珠材和12种饰品均须经三消实际采集才能解锁使用，每关六种且同时包含珠宝、水晶、木质、饰品四类，八关覆盖全部目录并循环。新存档零材料，旧库存保留但无来源的材料不能用于新DIY；保存时同时扣采集库存及实际库存，选用的饰品也扣1件。尺寸随成品保存。桌台素材可在仓库根目录运行 `cocos/tools/prepare-diy-art.py` 重建，原始参考文件名记录在该脚本中。新增浏览器验收 `scripts/test-cocos-diy-materials.mjs`。下文委托流程为历史版本记录。

每日签到由 `daily.ts` 实现：首页手动领取、七日连续奖励循环、北京时间零点更新、漏签重置、满额体力折金币。同一天和时钟回拨不重复领取。旧存档默认未签到，不影响材料来源；本地设备时间与本地存档用于离线签到。浏览器验收见 `scripts/test-cocos-daily.mjs`。

对话人物按当前说话人切换明暗：奶奶或阿禾发言时本人保持原色，另一人变暗；旁白和画外角色发言时，两人均变暗。透明人物图层从现有 `pencil-dialogue-stage.jpg` 原位拆出，背景、字号、对白框及存档保持原样。`python tools/prepare-dialogue-characters.py` 可重建两张图层；图层作为原插画的子节点，沿用其位置和尺寸。

完整游戏已迁入 `assets`，使用 **Cocos Creator 3.8.2 / TypeScript / 原生 2D UI**。

## 在 Creator 中运行

1. 用 Dashboard 打开本工程。
2. 等待资源导入，双击 `assets/scenes/Atelier.scene`。
3. 场景默认显示首页。若仍看到旧的空场景，先关闭 Atelier 场景标签，再双击重新打开；在层级选中 Canvas 后按 F 可聚焦。
4. 点击顶部「运行 / 预览」试玩。设计尺寸为 720 × 1280，电脑横屏会保留侧边留白。

场景已保存 Canvas、UI Camera 和十八个页面的原生布局。展开 `AtelierGame → Canvas → Atelier → EditableLayouts`，选中 EditableLayouts，在 `AtelierLayouts` 组件的 Page 下拉框切换首页、封面、委托、手作、消除、装修、图鉴、手账、比赛、参赛手作、订单交付、剧情对话、人物回忆、成品包装、故事解锁、暂停游戏、新订单、收藏详情。

子节点的 Position、Rotation、Scale、UITransform 尺寸，以及 Label 文字 / 字号 / 颜色 / 对齐、Sprite 的 SpriteFrame 都会在运行时读取。按钮事件与动态数值仍由 `AtelierGame.ts` 绑定：未修改的示例数值会跟随真实存档更新。请保留 AtelierLayout 组件和页面层级；重命名普通节点不影响绑定。新增按钮和修改玩法仍需配合脚本。棋盘格和手串槽可以移动；为保证网格与拖动规则，保持原有格子数量、珠槽尺寸和 UITransform 锚点。

所有插画、珠材和吊坠均按 SpriteFrame 原比例等比缩放，替换美术也会自动适配。UITransform 的宽高作为容纳范围，不再把人物强行拉伸填满。首页用原生 Mask 等比裁切横幅，委托与备料状态合为主卡片，故事 / 手账 / 比赛独立分组；委托每页三份并定位当前顾客，手账每页四段，心愿可展开全文。工坊保留圆形珠槽与透视托盘，原生编辑布局同步更新。

装修布局显示初始小店，升级后的新增家具细节、作品图鉴的已交付内容和弹窗由真实进度生成。矢量底板由 `AtelierLayout` 在编辑模式绘制，可编辑节点变换；复杂路径保存在 Drawing 字段中。`tools/generate-editor-layouts.cjs` 用同一套页面代码创建初始布局，已有布局默认拒绝覆盖，避免丢失编辑器里的修改。

## 委托经营主流程

确认交付后进入参考图形式的完整结算页：上方为等比递交礼盒插画，下方展示本次实际珠子与吊坠、金币、信誉增量和真实收藏解锁。奖励与结算回执一起保存，停在这页刷新会恢复回执，不再次扣库存或发奖。「继续营业」再接顾客回应与剧情；海风订单保留祝福回应，回头客订单继续派发下一份委托。仓库 `scripts/test-cocos-delivery.mjs` 验证六单、回头客、刷新、触屏继续及360/390/1440宽度。

首页「按单制作」、底部「手作」始终进入当前顾客委托，显示顾客、作品名、珠材数量与吊坠要求，并以「包装交付」结算。六份剧情委托完成后，继续轮流收到六种回头客追加订单，不再自动切换为自由 DIY。回头客订单同样检查配方、扣除实际库存、发放金币与口碑；每次交付清空当前草稿并推进下一单，重复点击不能重复结算。

旧存档保留金币、库存、未交付草稿、六份原作及剧情、海风回访和比赛记录。回头客作品另存最近六份，可在图鉴通过「查看回头客作品」切换；最初六份剧情原作与祝福卡长期保留。回头客交付不会重播第一次来店的剧情或重复发送赛事邀请。

## 第一轮新增 · 小满的海风订单

本轮范围为这一单的完整体验。有来历的珠子、奶奶主动日常、「我的心意」自由作品，以及其余五单的情绪扩展仍按后续批次制作，当前没有冒充已完成。

## 剧情对话界面

主线、三段家具支线、小满心意聊天、交付回应和装修日常采用参考图的全屏人物场景与底部对白框。背景人物使用提供的同一幅祖孙插画，保持原比例；标题、姓名、正文、选项和控制按钮为真实 Cocos 节点。当前未新增其他角色立绘或表情动画。

右上「记录」只展示已经读到的当前剧情对白，分页翻阅后「返回对话」或 Esc 回到原句；聊天记录显示已经了解的问题与回答。「跳过」主线会标记该段已读并收好对应手账记录，不改变金币或珠材；心意聊天中跳过仅离开，不自动解锁未问的细节。Esc 离开主线仍保留未读状态，可以在手账重温。已读剧情重温不会重复奖励。编辑器 Page「剧情对话」可调整该套界面，运行时仍使用实际说话人与对白。

## 人物回忆

关系阶段根据已读剧情、已交付作品和已了解的聊天细节派生，最高四格，小满最后一格需真实旅行回访。没有额外赠礼刷好感、货币或独立亲密度存档。「已知经历」按已读剧情收录该人物原话，可翻页并重温；未读场景不提前出现。相关订单显示实际收藏作品或当前待做委托。查看和重温不会发奖或改变草稿、库存；「开始制作 · 当前委托」始终回当前顾客手作台。编辑器 Page「人物回忆」可修改布局。

## 新增 · 偶尔参加一场串珠赛

首页插画右下角新增「参加比赛」，完成第 1、3、5 份委托分别收到「街角花园灵感赛」「海风配色交流赛」「小城星光手作赛」邀请。比赛板块始终可打开，尚未邀请的赛事显示解锁条件。每场可提交一件作品；提交前可以退出续做，换赛题时会先确认放下未提交的参赛草稿。

赛事提供六色练习珠材，免费参加，不消耗库存与体力；使用同一套十二槽点珠、拖动换位、取下、撤销和选吊坠操作，参赛草稿独立保存，不覆盖顾客委托。评分规则：主题色至少 6 颗得 45 分，辅助色至少 3 颗得 20 分，主题吊坠 10 分，相对珠槽同色呼应最多 25 分。不足指定数量按比例评分。90 / 75 / 60 分分别获得金 / 银 / 铜奖，其余作品获得参与纪念。

提交后展示作品、四项分数、街坊评语、纪念奖牌与金币。金币一次入账，重看作品不再发奖；成绩和参赛作品保存在比赛板块，随原有 JSON 存档导入导出。该版本为本地街坊评审挑战，包含三场主题赛事。

## 背景音乐

设置（右上角齿轮）→「背景音乐 · 切歌 / 音量」可以直接点选六首音乐，也可点「下一首」。支持拖动 / 点击音量条、加减按钮、0–100% 音量、暂停 / 播放；默认音量 35%，曲目与音量保存到本地存档，导入后同步恢复。屏幕阅读器提供同一音量滑杆。

曲目为用户提供的「宁静的微光」「宁静治愈」「治愈钢琴」「治愈少女」「治愈时光」「治愈系少女」，原始 MP3 位于 `E:/Game/美甲/音乐`，以原始音频内容复制至 `assets/resources/music`，未移除源文件中的声音或水印。仅在选中时加载，当前曲目循环播放；切换不叠音，页面切换不重头播放，应用后台暂停。浏览器首次播放需要点击或触摸解锁，操作音效开关与音乐独立。

## 存档迁移

原网页「设置 → 导出」得到的 JSON 可粘贴进本版「设置 → 导出 / 导入存档」。导入前会显示进度概况并要求在游戏中确认覆盖。网页与 Cocos 版使用同一套存档校验及规则；不同站点、浏览器和原生应用之间不会自动共享 localStorage。

通用页头去掉资源数字前的「珠 / 金」，保留图标与真实数值，屏幕阅读器仍能读出资源含义。资源栏收紧，为设置旁的音符按钮留出空间。单击音符在 320ms 双击窗口结束后切到下一首并开启音乐；双击只打开现有切歌 / 音量面板，不误切歌。滑杆、加减键、0–100% 音量与曲目均沿用现有存档。离开页面、打开其他弹窗或切至后台时取消待执行单击；拖出和取消触摸不触发。无障碍按钮可直接切歌或打开音量，原设置 / 暂停音乐入口继续可用。场景只替换六组通用页头，其余对象保留，备份见 artifacts/Atelier-before-header-music.scene。
